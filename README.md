# Shoes

Простой проект на Vite: HTML, SCSS и JavaScript. Структура и обработка HTML-шаблонов взяты из `vintage/frontend`; команды запуска доступны прямо из корня shoes.

## Запуск

Нужен Node.js 20.19+ в ветке 20 или 22.12+.

```bash
npm ci
npm run dev
```

`npm run build` собирает сайт в `dist/`, `npm run preview` запускает просмотр сборки.

## Структура

```text
index.html                      Главная страница
src/
  _layouts/base.html            Общий HTML-шаблон
  _components/
    header/                     HTML и SCSS шапки
    footer/                     HTML и SCSS подвала
    sections/hero/              HTML и SCSS секции
  _pages/home/home.scss         Стили главной страницы
  assets/
    _styles/                    Сброс и общие переменные
    _images/                    Изображения, обрабатываемые Vite
    _fonts/                     Локальные шрифты
  global.scss                   Общие стили
  main.js                       Точка входа JavaScript
public/                         Файлы, копируемые в сборку без обработки
vite.config.js                  Vite и обработка HTML-шаблонов
```

## Добавить страницу

Создайте, например, `catalog.html` рядом с `index.html` — все HTML-файлы в корне автоматически попадают в сборку:

```html
<!-- @layout src/_layouts/base.html -->
<main>
  <!-- @include src/_components/sections/hero/hero.html -->
</main>
```

`@slot` в шаблоне обозначает место для содержимого страницы. `@include` поддерживает вложенные компоненты, пути относительно текущего файла и алиас `@/` для `src/`.

## Добавить компонент

Создайте папку в `src/_components/` с HTML, SCSS и при необходимости JavaScript. В HTML подключите стили:

```html
<link rel="stylesheet" href="./component.scss">
<section class="component">Содержимое</section>
```

Подключите HTML через `@include`, а JavaScript импортируйте в `src/main.js`. SCSS компонентов автоматически переносится в `<head>` и подключается один раз на страницу. Изменения HTML-компонентов и шаблона перезагружают страницу в dev-режиме.

Алиас `@/` работает в JavaScript и HTML-атрибутах `src`, `href`, `poster`, `srcset`. Например: `<img src="@/assets/_images/product.webp" alt="Обувь">`.

Для публикации в подпапке задайте базовый путь при сборке:

```bash
VITE_BASE_PATH=/shoes/ npm run build
```

Ссылки на страницы задавайте относительно текущей страницы, если планируете публикацию в подпапке. Библиотеки для слайдеров, анимаций и других задач можно установить по мере необходимости.

## Адаптив

`src/assets/_styles/_breakpoints.scss` — единый набор точек перехода:

| Имя | Ширина |
| --- | --- |
| `mobile` | 480px |
| `tablet` | 768px |
| `laptop` | 1024px |
| `desktop` | 1280px |
| `wide` | 1600px |

Подключение в SCSS компонента:

```scss
@use '@/assets/_styles/breakpoints' as bp;

@include bp.down(tablet) {
  .example { grid-template-columns: 1fr; }
}
```

`down` включает указанную ширину, `up` работает выше неё. Типографика, отступы контейнеров и секций плавно меняются через `clamp()`. Стили адаптива находятся рядом с десктопными стилями соответствующего компонента. Высота фиксированной шапки задаётся через `--header-height`, отступ страницы и положение sticky-элементов используют ту же переменную.

## Меню и каталог

`src/navigation.js` отвечает за выпадающие разделы, мобильную навигацию и окно входа. Меню закрываются по Escape и клику снаружи, диалоги используют нативное управление фокусом.

`src/catalog.js` содержит только открытие и закрытие фильтра: выше 1024px он раскрывается горизонтально над карточками, на 1024px и меньше используется отдельная панель. При изменении ширины открытый фильтр переключается между этими режимами. Каталог, счётчик и карточки статические: фильтрация, сортировка, поиск, избранное и сохранение параметров в URL будут подключаться при переносе на WordPress. Элементы формы оставлены для верстки и проверки визуальных состояний.
